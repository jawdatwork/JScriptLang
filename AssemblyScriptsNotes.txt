assembly_script
  \-> print_text function  +++
  \-> special command list ***

special command list is a lit of commands
that allow the User to use calculation functions
with the previous executable; with the computer.

example calculation function:
  set var to value
  if var is value execute command
  else execute other command
  ... display_rect, play_audio_clip, display_window

Assembly Script
  \-> Lines Of Code
        [Using] Plain Line Of Text
        [Using] Print Text Commands
        [Using] Special Calculation Commands

Solution:
For each J Script or JAssem Script
  they are [Using]
    Plain Text, Line Of Text/Code
    Print Text Command
    Special Calculation Command
    
In order to
  print_text, display_rect, play_audio_clip, or display_window.
